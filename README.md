# Маршрут поступления (рабочее название)

AI-сервис персонального маршрута поступления в вузы Казахстана.
Кейс 02 — LOCUS Startup Hackathon 2026, код кейса `LOCUSCASE2`.

## Задача

Абитуриенту нужен не ещё один список вузов, а понятный маршрут: куда поступать, почему это
подходит именно ему и что делать дальше. Информация о поступлении разрознена, а типовые
AI-чаты дают общие советы без персонализации и плана действий.

## Решение

Короткая анкета → диагностика профиля → минимум 3 рекомендованных вуза с объяснением
«почему подходит» (rule-based скоринг) → сравнение вариантов → персональный roadmap с
шагами и дедлайнами → один ближайший следующий шаг с отметкой прогресса. Рекомендации и
roadmap пересчитываются при изменении ключевых ответов (интересы, бюджет, балл ЕНТ, город).

## Сегмент

Ученики 10–11 классов и выпускники школ, поступающие в бакалавриат в Казахстане.

## Стек

- Next.js 14 (App Router), React 18
- Tailwind CSS
- Состояние профиля — React Context + `localStorage`, без выделенного backend
  (разрешено правилами кейса: «заменить сложный backend локальным хранением, если полный
  путь работает»)

## Архитектура

```
app/
  page.js                  — Вход
  profile/page.js          — Анкета
  diagnosis/page.js        — Диагностика
  recommendations/page.js  — Рекомендации
  compare/page.js          — Сравнение
  roadmap/page.js          — Roadmap
  next-step/page.js        — Следующий шаг
lib/
  ProfileContext.js        — состояние профиля (localStorage)
  data/universities.js     — датасет вузов (демо-данные)
  recommend.js             — rule-based логика рекомендаций
  roadmap.js               — генерация шагов roadmap
  constants.js             — справочники (интересы, города, бюджет, шаги)
components/
  StepHeader.js             — индикатор шага пути (где я нахожусь)
```

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

## Тестовый сценарий

1. Открыть главный экран → «Начать за 2 минуты».
2. Заполнить анкету (класс, интересы, балл ЕНТ, бюджет, город) → «Показать диагностику».
3. Посмотреть диагностику → «Смотреть рекомендации».
4. Выбрать 2 вуза кнопкой «Сравнить» → «Сравнить выбранные».
5. Перейти к roadmap, отметить прогресс по шагам.
6. Открыть «Что делать дальше?» — убедиться, что показан именно первый невыполненный шаг.
7. Вернуться в анкету, изменить бюджет или интересы — убедиться, что рекомендации и roadmap
   заметно меняются.

## Данные и источники

Датасет вузов в `lib/data/universities.js` помечен `isDemoData: true` — проходные баллы и
стоимость обучения указаны приблизительно. **Перед финальной сдачей необходимо сверить
актуальные цифры с официальными сайтами вузов и Univer.kz**, либо оставить явную пометку
«демо-данные» на экране рекомендаций (уже реализовано).
